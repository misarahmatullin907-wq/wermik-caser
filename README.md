# WERMIK CASES — демо-проект

Виртуальный симулятор открытия кейсов. Все монеты и предметы существуют только внутри проекта и не имеют денежной стоимости.
Никаких платежей, ставок, обмена, вывода предметов и подключения Steam.

## Запуск
- Локально: распакуйте архив и откройте `index.html` в браузере (папка `items/` должна лежать рядом).
- Netlify: перетащите папку целиком (index.html + items/) на https://app.netlify.com/drop. Сборка не нужна.

## Состав
- `index.html` — весь интерфейс, стили и логика (HTML/CSS/JS, без внешних API; подключены только шрифты Google Fonts).
- `items/` — 72 картинки предметов (оружие, ножи, перчатки), предоставлены владельцем проекта.

## Что есть
Кейсы и страницы кейсов, рулетка (x1–x6), инвентарь (просмотр, продажа за виртуальные монеты, удаление), апгрейд,
задания и скин раз в 10 минут, профиль с историей, сброс прогресса. Прогресс хранится в localStorage.
